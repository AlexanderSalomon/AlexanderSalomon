# Rascunho — Sort by / filtros de grupos

Mockup HTML interativo da seção de filtros e ordenação da lista de grupos de convidados.

## Abrir

```bash
# na pasta do rascunho
python3 -m http.server 8765
# abrir http://127.0.0.1:8765
```

Ou abra `index.html` no navegador.

## Telas

1. **Lista de grupos** — busca, lado (Todos/Noivo/Noiva), chips de categoria, botão Ordenar
2. **Sheet Ordenar** — Nome, recentes, status, tamanho do grupo
3. **Nova categoria** — nome, lado padrão, cor do chip

## Interações no mockup

- Trocar lado (segmented control)
- Ativar/desativar chips de categoria
- Abrir sheet de ordenação no botão **Ordenar: Status**
- Escolher cor na tela de nova categoria
